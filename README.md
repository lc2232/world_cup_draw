This project is designed to be a locally hosted application that allows users to submit a list of Names and then names of teams in the World Cup. It them displays a GUI of the tournament knockout along with a list of each users name, and their relevant teams remaining in the tournament.

Example:

"Luke" : Bolivia, England, France...
"Viv" : Argentina, Spain, Portugal...
...

The GUI will then display the lists of the users with their remaining teams as a sublist. Then there will be another window (perhaps the same window but as a separate panel) with a tournament style outline.

e.g.

Luke
- Bolivia
- England
- ~~France~~
...

Viv
- ~~Argentina~~
- Spain
- ~~Portugal~~
...

I would like this GUI to be styled in a sort of black and green colour scheme, in an 8-bit style.
